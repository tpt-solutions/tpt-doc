# Contributing to tpt-doc

Contributions are made through **GitHub issues only**. Please do not open pull requests.

- **Bug report:** use the [Bug report](.github/ISSUE_TEMPLATE/bug_report.md) template. Include the crate and version, what happened versus what you expected, and a minimal input. Redact any personal or health data.
- **Feature request:** use the [Feature request](.github/ISSUE_TEMPLATE/feature_request.md) template. Include the use case and the relevant standard or spec section.
