## [Unreleased]

### Added
- Initial workspace scaffold with 7 crate skeletons
- `tpt-doc-core`: shared traits, zero-copy buffer abstraction, unified error types
- `tpt-doc-spreadsheet`: streaming OOXML/CSV parsing placeholder
- `tpt-doc-fhir`: HL7 FHIR R5 typed resource builder placeholder
- `tpt-doc-edi`: EDIFACT/X12 streaming parser placeholder
- `tpt-doc-pdf`: pure-Rust PDF generation placeholder
- `tpt-doc-sign`: PAdES/XAdES/CAdES signing placeholder
- `tpt-doc-layout`: headless HTML/CSS-to-PDF layout placeholder
- GitHub Actions CI (fmt, clippy, deny, test, coverage)
- mdBook documentation skeleton
