# Changelog

All notable changes to `tpt-doc-mcp` are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - 2026-11-10

### Added

- MCP server over stdio using JSON-RPC 2.0, protocol version `2024-11-05`.
- Tools: `validate_document`, `convert_hl7_to_fhir`, `extract_text` (DOCX only)
  and `generate_invoice`.
- `tpt-mcp` binary.
